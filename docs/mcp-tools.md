# MCP-инструменты агента Pitlane

Агент помогает клиенту подобрать машину и оформить аренду. MCP-сервер: `http://localhost:8000/mcp` (Streamable HTTP), заголовок `Authorization: Bearer <токен>` — токен агента выдаёт `POST /api/agent/token`. Код — `backend/app/mcp_server.py`, цикл агента — `backend/app/agent.py`.

Инструменты делятся на два типа:

- **Чтение** — агент вызывает сам, без подтверждения. Результат показывается сообщением или карточками `CarCard`.
- **Изменение** — агент только *предлагает* действие. Сервер не выполняет его сразу, а создаёт черновик со статусом `proposed`. В чате появляется карточка `AgentAction`. Действие выполняется, только когда клиент нажмёт «Подтвердить».

## Главные правила

1. **Клиента определяет сессия, а не агент.** Ни один инструмент не принимает `user_id`. Сервер берёт пользователя из Bearer-токена агента. Так агент не сможет посмотреть или изменить чужую бронь, даже если его попросят.
2. **Подтверждение идёт в обход агента.** Кнопка «Подтвердить» в карточке вызывает `POST /api/actions/{action_id}/confirm` напрямую с фронтенда. У агента нет инструмента `confirm_action`, поэтому он не может подтвердить действие сам за себя.
3. **Деньги и документы агент не трогает.** Оплату клиент проводит на странице оплаты, а фото прав загружает в профиле. Агент может только дать ссылку и сказать, что осталось сделать.
4. **Цены всегда считает сервер.** Агент не складывает суммы сам, а берёт их из `quote_price`.

## Чтение — без подтверждения

| Инструмент | Что делает | Параметры | Возвращает |
|---|---|---|---|
| `search_cars` | Ищет машины по фильтрам | `date_from?`, `date_to?`, `body_type?` (купе, кабриолет, седан), `max_price_per_day?`, `min_power?`, `seats?`, `brand?`, `sort?` (price, power, accel), `limit?` (по умолчанию 6) | Список: `id`, `name`, `price_per_day`, `power`, `accel`, `seats`, `status`, `image_url` |
| `get_car` | Подробная карточка машины | `car_id` | Характеристики, фото, ограничения (пробег в сутки, минимальный возраст и стаж), депозит |
| `check_availability` | Свободна ли машина на даты | `car_id`, `date_from`, `date_to` | `available: bool`; если занята — ближайшие свободные окна |
| `quote_price` | Расчёт стоимости | `car_id`, `date_from`, `date_to`, `extras?` (коды доп. услуг) | Строки расчёта, итог, депозит (те же поля, что у `BookingSummary`) |
| `list_extras` | Доп. услуги | — | `code`, `name`, `price`, `per` (сутки или аренда): полная страховка, детское кресло, доставка |
| `list_locations` | Точки выдачи | — | Адрес, часы работы |
| `get_rental_terms` | Условия аренды | `topic?` (deposit, mileage, fines, age, cancellation) | Текст правил. Агент отвечает по нему, а не по памяти |
| `get_my_profile_status` | Готов ли клиент арендовать | — | `documents_verified`, `phone_verified`, чего не хватает. Без персональных данных |
| `list_my_bookings` | Брони клиента | `status?` (upcoming, active, past) | Номер, машина, даты, сумма, статус |
| `get_booking` | Одна бронь | `booking_id` | Детали брони, статус оплаты, можно ли отменить бесплатно |

## Изменение — через карточку подтверждения

Каждый из этих инструментов возвращает `{ action_id, status: "proposed", summary }`. Фронтенд рисует по нему `AgentAction` с параметрами из `summary`.

| Инструмент | Что предлагает | Параметры | После подтверждения |
|---|---|---|---|
| `create_booking` | Забронировать машину | `car_id`, `date_from`, `date_to`, `location_id`, `extras?` | Бронь создаётся со статусом «Ждёт оплаты», машина держится 30 минут. Клиент получает ссылку на оплату |
| `change_booking_dates` | Перенести даты | `booking_id`, `date_from`, `date_to` | Пересчёт цены. Если выходит дороже — доплата по ссылке |
| `update_booking_extras` | Добавить или убрать доп. услуги | `booking_id`, `add?`, `remove?` | Пересчёт цены |
| `cancel_booking` | Отменить бронь | `booking_id`, `reason?` | Отмена по правилам: бесплатно раньше чем за 24 часа, позже — `failed` с причиной |
| `request_manager` | Позвать живого менеджера | `topic`, `message` | Заявка менеджеру, клиенту приходит номер обращения |

`request_manager` тоже идёт через подтверждение: клиент должен видеть, что его переписку передадут человеку.

## Инструменты интерфейса чата

Их выполняет не MCP-сервер, а цикл агента в `agent.py`: они ничего не меняют, а превращаются в элементы чата.

| Инструмент | Что делает |
|---|---|
| `show_cars` | Карточки `CarCard` по списку `car_ids` (до 4). Статус на даты берётся из последнего `search_cars` |
| `suggest_replies` | 2–3 кнопки быстрых ответов под лентой |

Сайт сообщает агенту, какую страницу видит клиент (`page` в `POST /api/chat`), поэтому «эта машина» и «эти даты» понятны без уточнений.

## Жизненный цикл карточки действия

```
агент (или сайт) вызывает create_booking
        │
        ▼
 proposed ── «Отменить» ──► cancelled (карточка серая, агент узнаёт об отказе)
        │
   «Подтвердить» (фронтенд → /api/actions/{id}/confirm)
        │
        ▼
 running ──► done   (бронь создана, ссылка на оплату)
        └──► failed (причина в note: даты заняли, бронь уже не отменить бесплатно…)
```

Черновик `proposed` живёт 15 минут. Если клиент не ответил, он истекает, и агент предлагает заново.

## Пример диалога

1. Клиент: «Хочу кабриолет на выходные, до 30 тысяч в сутки».
2. Агент → `search_cars({ body_type: "cabriolet", date_from: "2026-10-17T10:00", date_to: "2026-10-19T10:00", max_price_per_day: 30000 })` → `show_cars([...])`.
3. Клиент: «Давай BMW, со страховкой».
4. Агент → `quote_price(...)` → `create_booking(...)` → в чате карточка `AgentAction` «Ждёт подтверждения» с датами, суммой и депозитом.
5. Клиент нажимает «Подтвердить» → фронтенд вызывает `/api/actions/{id}/confirm` → карточка переходит в «Выполнено», появляется ссылка на оплату.

## Сайт идёт тем же путём

Кнопки сайта («Забронировать», «Перенести даты», «Услуги», «Отменить бронь») вызывают те же действия через `POST /api/actions` и показывают ту же карточку `AgentAction`. Разница только в том, кто подготовил черновик: агент или форма. Подтверждает всегда клиент.

## Открытые вопросы

- Нужен ли агенту доступ к истории прошлых аренд для рекомендаций («в прошлый раз вы брали 911»)?
- Чат без входа: сейчас он просит войти. Можно разрешить поиск и цены анонимно.
