# Input

Текстовое поле с подписью, подсказкой и ошибкой. Подпись — `label`, прописными, всегда над полем (плейсхолдер её не заменяет). Ошибка через `error` заменяет подсказку, красит рамку в `stop` и связывается с полем через `aria-describedby`.

Передаёте: `label`, `hint` или `error`, остальные атрибуты `<input>` (`type`, `value`, `onChange`, `placeholder`). Ширину задаёт контейнер.

- Текст ошибки говорит, как исправить: «Нужно 10 цифр: серия и номер», а не «Неверный формат».
