# Button

Кнопка действия. `primary` (papaya) — не больше одной на экран, для главного действия: «Забронировать», «Оплатить». `secondary` — по умолчанию, для всего остального. `ghost` — третьестепенные действия в карточках и тулбарах. `agent` (синяя) — только «Подтвердить» в карточке `AgentAction`, чтобы клиент видел, что запускает действие агента.

Передаёте: `children` (глагол, с прописной только первое слово), `onClick`, при необходимости `size="lg"` для героя и итога брони, `block` — на всю ширину. Остальные атрибуты уходят в `<button>`.

- Делайте: «Забронировать», «Изменить даты», «Отменить бронь».
- Не делайте: «ОК», «Да», две papaya-кнопки рядом, синюю кнопку вне чата агента.
