# BookingSummary

Итог бронирования на плите `carbon`: машина, даты выдачи и возврата, расчёт по строкам, депозит и сумма. Ставится справа от формы на десктопе и внизу на телефоне. Сумму компонент считает сам: сутки × цена + доп. услуги (депозит в итог не входит).

Передаёте: `car`, `from`, `to` (уже отформатированные строки), `days`, `pricePerDay`, `extras`, `deposit`, `onConfirm`. Без `onConfirm` кнопки нет — так итог показывается внутри чата агента.
