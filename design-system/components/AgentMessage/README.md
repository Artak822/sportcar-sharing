# AgentMessage

Сообщение в чате с ИИ-агентом. Сообщения агента — на `agent-soft` с аватаром слева, сообщения клиента — на `surface-raised` справа. Внутрь можно класть `CarCard`, `BookingSummary` и `AgentAction`.

Передаёте: `role` (`agent` или `user`), `time` («14:02»), `children`.

- Агент пишет от первого лица и коротко, с числами: «Нашёл два кабриолета…».
