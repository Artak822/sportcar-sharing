# SpecList

Табло характеристик на странице автомобиля: крупные моноширинные цифры с единицами, как на табло хронометража. `dark` — версия для плиты `carbon` в герое.

Передаёте: `items` — массив `{label, value, unit}`. Значение — строка с десятичной запятой («3,5»), единицы отдельно. 3–6 пунктов; колонки перестраиваются сами.
