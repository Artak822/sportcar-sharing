# CarCard

Карточка автомобиля в каталоге и в ответах агента: фото 16:9, статус, три ключевые характеристики, цена за сутки и кнопка брони. Если машина занята или на обслуживании, кнопка становится вторичной и неактивной.

Передаёте: `name`, `pricePerDay` (число в рублях), `specs` (`power` в л.с., `accel` — разгон 0–100 км/ч в секундах, `seats`), `status`, `imageSrc`, `onBook`. Без `imageSrc` показывается заглушка. Ширину задаёт сетка каталога: колонка 280–360px.

- Агент показывает найденные машины этими же карточками, не текстом.
