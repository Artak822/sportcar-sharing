# Badge

Короткий статус или метка. Тоны `available`, `booked`, `service` подписываются сами («Свободен», «Занят», «На обслуживании»): цвет всегда идёт вместе со словом. `agent` — только для состояний, связанных с ИИ-агентом. `neutral` — для категорий (кузов, привод).

Передаёте: `tone` и при необходимости `children`. Одно-два слова, без точки.
