# AgentAction

Карточка действия, которое ИИ-агент выполняет на сайте через MCP-инструмент. Показывает имя инструмента, что именно произойдёт, параметры и статус. Это главный механизм доверия: всё, что меняет данные (бронь, отмена, оплата, смена дат), агент сначала показывает со статусом `proposed` и ждёт «Подтвердить».

Статусы: `proposed` → `running` → `done` или `failed`; `cancelled`, если клиент нажал «Отменить». Кнопки есть только у `proposed`. При `failed` в `note` объясните причину и следующий шаг.

Передаёте: `tool` (имя MCP-инструмента), `title` (глагол + объект), `details` — массив `{label, value}`, `status`, `note`, `onConfirm`, `onCancel`.

- Действия только на чтение (`search_cars`, `check_availability`) подтверждения не требуют: сразу `done` или вообще без карточки.
